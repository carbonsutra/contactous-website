# Stylos

Analyze text and documents for authorship signals with explainable, structured analysis results.

> **Demo content:** The examples below are illustrative placeholders for product discovery and UI development. Confirm production endpoints, authentication, and response schemas with the product team before integrating.

## What you can do

- Integrate Stylos into an existing application through a documented API workflow.
- Validate requests and inspect structured responses during development.
- Adapt sample payloads to your domain, policies, and data requirements.

## Example request

```http
POST /api/v1/stylos/demo
Authorization: Bearer YOUR_API_KEY
Content-Type: application/json
```

{
